# AI智能伴侣 💬
## 项目简介
本项目基于Python + Streamlit搭建交互式Web对话应用，接入DeepSeek大模型API，实现可自定义人设的AI虚拟伴侣聊天系统。
支持多会话管理，聊天记录本地JSON持久化存储；用户可以自定义AI伴侣昵称、性格特征，AI严格按照设定人设进行简短生活化对话，采用流式输出模拟打字聊天效果。

## 技术栈
- 开发语言：Python
- Web框架：Streamlit
- 大模型：DeepSeek（兼容OpenAI接口）
- 其他库：json、os、datetime

## 功能特性
1. **自定义AI人设**：侧边栏可修改伴侣昵称与性格描述，系统提示词自动代入角色设定，对话风格贴近微信日常聊天，支持emoji。
2. **多会话管理**
    - 新建会话：一键开启新对话，自动保存上一轮会话记录
    - 历史会话加载：读取`sessions`目录下所有对话文件，按时间倒序展示
    - 删除会话：支持删除指定会话，若删除当前会话会自动重置对话
3. **对话持久化**：每次对话结束自动将聊天记录保存为JSON文件，重启程序可加载历史对话。
4. **流式输出**：大模型返回内容逐字实时展示，模拟在线打字效果。
5. 网页聊天界面区分用户消息与AI消息，自动渲染历史聊天记录，页面采用宽屏布局。
